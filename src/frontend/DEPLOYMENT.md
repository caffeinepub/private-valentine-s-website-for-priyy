# Love Slides - Production Deployment Guide

This guide walks you through deploying the Love Slides application to the Internet Computer (ICP) mainnet.

## Prerequisites

- [DFX CLI](https://internetcomputer.org/docs/current/developer-docs/setup/install/) installed (version 0.15.0 or later)
- Node.js and pnpm installed
- ICP cycles for deployment (obtain from [cycles faucet](https://faucet.dfinity.org/) or purchase)
- Git repository with your code
